# Task Master

A simple browser-based task manager for creating, viewing, and deleting personal tasks.

## Overview

Task Master provides a minimal interface for adding daily tasks and managing the current task list. Tasks are stored in the browser using `localStorage`, so saved tasks can remain available when the page is reopened in the same browser.

## Features

- Add a task from the input field
- Display saved tasks in a list
- Delete individual tasks
- Persist tasks with browser `localStorage`
- Lightweight, dependency-free frontend

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage API

## Run Locally

Clone the repository and open `index.html` in a modern web browser.

```bash
git clone https://github.com/Scarlet-Twinz/Ella-task-manager-pro.git
cd Ella-task-manager-pro
```

No package installation or backend server is required.
